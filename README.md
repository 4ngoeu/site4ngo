# 4ngo.eu

Представителният сайт на **4ngo**. Статичен сайт без база данни, бисквитки и външни услуги.

Марката, цветовете и текстовете следват [4ngoeu/projectgaude](https://github.com/4ngoeu/projectgaude).

## Езици

Английски (`/en/`), френски (`/fr/`), немски (`/de/`) и български (`/bg/`).
Началната страница `/` пренасочва към езика на браузъра, а по подразбиране към английски.

## Структура

```
src/i18n/<език>.json   текстовете за всеки език
build.mjs              генерира страниците от текстовете
assets/                CSS, шрифтове (самостоятелно хоствани) и лога
en/ fr/ de/ bg/        генерираните страници (не се редактират на ръка)
index.html             пренасочване по език
sitemap.xml robots.txt
```

## Промяна на текст

1. Редактирайте `src/i18n/<език>.json`.
2. Изпълнете `node build.mjs` (Node 18+).
3. Качете цялата папка на хостинга.

## Нов език

1. Копирайте `src/i18n/en.json` като `src/i18n/<код>.json` (например `it.json`) и преведете текстовете.
2. Добавете кода в `LANGS` в `build.mjs`.
3. Изпълнете `node build.mjs`.

## Преглед локално

```bash
python3 -m http.server 8000
```

След това отворете http://localhost:8000.

Иконите на социалните мрежи са от [Bootstrap Icons](https://icons.getbootstrap.com/) (MIT).
